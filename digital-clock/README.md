# World Clock

A responsive digital clock displaying live time across multiple time zones.

## Features

- Live local time and detected timezone
- New Delhi, New York, London, and Tokyo by default
- Add or remove locations
- 12-hour / 24-hour format switch
- Light and dark themes
- Responsive, dependency-free static app

Open `digital-clock/index.html` in a browser, or deploy the `digital-clock` folder to static hosting.
